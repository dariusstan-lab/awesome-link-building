## Free Tools

- [Moz Link Explorer](https://moz.com/link-explorer) — Free domain authority checker (10 queries/month).
- [Ahrefs Webmaster Tools](https://ahrefs.com/webmaster-tools) — Free site audit + backlink data for verified sites.
- [Majestic](https://majestic.com/reports/majestic-million) — Free Trust Flow + Citation Flow snapshots.
- [Ubersuggest](https://neilpatel.com/ubersuggest/) — Free backlink overview (limited daily).
